Paste a JSON array. Pre-transforms run first on raw rows: each entry is (item, row) => … with the original row as row, and results replace those keys on a copy that becomes the working dataset. Chart transforms run on that row for plotting only. Derived fields add new keys: each function is (row) => … and receives the working row (after pre-transforms); results are written in key order so later entries can use earlier derived columns. String fields are skipped for charting. Leave pre-transforms blank (or use {}) to skip that stage. Pick the X-axis field (or row index) and which Y fields to plot — Original lists data/pre columns; Derived lists only names you define in Derived fields (blur that box to refresh the lists). Click Draw charts when ready.
