JSON diff

Paste payloads in Left and Right, format the left pane, search/highlight against the formatted Left view, and diff Left vs Right. Everything runs locally (nothing is uploaded).

  • Validate & format — pretty-print or minify Left JSON; errors show JSON.parse position hints.
  • Search & highlight — literal or regex on the formatted Left preview; Next / Prev through hits.
  • Deep diff — compares Left to Right; arrays by index; object keys merged. Filter diff lines by path substring.
  • Stats — structure tallies computed from Left JSON after parse.

Run Format Left or Parse Left & stats, then search. Hits use yellow markers; the active jump target is darker.
