JSON inspector

Paste API or log output, then format, search, diff against a second snapshot, and skim structure stats—all in the browser (nothing is uploaded).

  • Validate & format — pretty-print or minify; errors show JSON.parse position hints.
  • Search & highlight — literal or regex, case option; jump next / previous hit in preview.
  • Deep diff — positional array compare; keys merged for objects; filter paths by substring.
  • Stats — node counts, max depth, string / number tallies after parse.

Run Format primary or Parse & show stats, then use search. Hits use yellow markers; the active jump target is darker.
